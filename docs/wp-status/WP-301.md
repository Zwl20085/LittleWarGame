# WP-301 — 3.0.1 full auto (斗蛐蛐) + inf_guns removal — status

Branch `fix/v3.0.1-auto` from `main` at feed11f (3.0.0). Not pushed / merged.

## User requirement
A player must be able to do nothing and just watch: every 3.0 system runs for the player's faction
by default, with a take-over toggle, exactly like 2.2.1's `Auto-invest`.

## Done
- `Faction.autoResearch` (default on): `upgradeSecond` runs `aiBuy` for the player too; priority
  from the player's doctrine (doctrines on) else personality. Manual purchase leaves it on; off
  returns the fund (`stopAutoResearch`). Toggle in the Upgrades panel and the economy panel.
- `Faction.autoEngineering` (default on): `thinkTransport` runs for the player (rail repair, road
  links, zone links); `Faction.autoEngReason` (`eng.why.*`) says why no job started. Toggle and
  reason in the Engineering popover. Manual jobs still work.
- `Faction.autoCommand` (default on): `chooseDirective` runs for the player while
  `autoCommandActive` — the player's doctrine profile (`profileById`) through `doctrineChoice`
  (finisher first, as for the AI). A manual directive other than `advance` pauses it for
  rules `command.auto_resume_s` (600 s) after it was given; a matching auto choice adopts the
  manual directive (it becomes the HQ's own). Turning the toggle on hands the directive back at
  once. HQ card: 自动统帅 / Auto HQ toggle, the HQ's directive or the time left on the player's
  order. Force toggle unchanged; spectate unchanged (all AI).
- Custom game: 玩家作风 / Your doctrine (slot 0 of `aiDoctrines`, default random); Quick Battle
  still draws one per slot.
- Commands `setAutoResearch` / `setAutoEngineering` / `setAutoCommand` (boolean-validated,
  src/sim/commands/auto.ts); the flags ride the faction snapshot; nothing persists across matches.
- Removed (user instruction mid-task): the infantry attached-gun upgrade `inf_guns` — rules items /
  effects, doctrine upgrade lists, UPGRADE_PRIORITY, upgradekit gun fire + `upgGunAt`, squad kit /
  refit bits, render gun team, engagement-lab pillbox scenario, tests, i18n, UPGRADES.md,
  BALANCE_SPEC §10.2, README (en + zh, GIF kept, caption no longer names the gun team). 12 items.
- Docs: README Controls line + "3.0.1" note (en + zh), UPGRADES.md, DOCTRINES.md. Version 3.0.1.
