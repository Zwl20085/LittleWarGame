## 状态与阅读原则

- **用户需求**：二战背景；只有即时战斗；城市经济集成；资源可托管；玩家配置出兵；自动部队交战；可观察战线、装甲、炮兵、空袭、步兵、筑垒和地形高差；支持多个电脑混战。
- **设计建议**：本文提出的具体规则，作为可修改的原型基线。
- **已通过对话确认**：电脑横屏、30—45 分钟；精致哑光微缩沙盘；二战作战室 UI；分层信息；默认自动且可框选细操；默认全图可见，另有战争迷雾模式。
- **建议与待细化**：45° 可调斜俯视（用户提出可以考虑）；正交/透视比较；装备年代和具体型号；精细材质与实际 UI 画面，需要后续原型收敛。
- **初始数值**：用于第一次实现和实验的假设，没有经过实机平衡验证。
- **未来扩展**：不是当前里程碑的默认任务。

发生冲突时，最新用户决定优先。规则与公式以 `BALANCE_SPEC.md` 为解释来源，种子值以 `data/` 为机器读取来源；修改时必须同步。不得把文档中的候选方案同时实现成正式要求。

建议先读游戏策划案第 1—5 节，再读开发交接；实现战斗或经济时完整阅读数值文档。视觉方向已确认，具体色值、尺寸和投影仍是建议，后续 agent 不得混淆两者。
