# LittleWarGame 视觉与 UI/UX 规格

版本 0.1。本文记录对话已经确定的方向，并提供可落地的界面规则。像素尺寸、色值、材质参数是建议种子，需通过实机画面迭代；不是已经完成的美术。

## 1. 对话结论

| 项目 | 用户选择 / 状态 |
|---|---|
| 战场风格 | 微缩沙盘；精致模型感；哑光涂装；细节简化、比例可信；烟火较真实 |
| UI 气质 | 二战作战室：纸质地图、军用标签、机械仪表 |
| 信息密度 | 分层显示；资源、战线、出兵常驻；选中后展开详细状态 |
| 指挥 | 默认自动，可框选、移动、集火、撤退 |
| 敌军可见性 | 默认全图可见，另提供战争迷雾模式 |
| 平台 / 局长 | 电脑横屏，30—45 分钟 |
| 相机 | 用户提出可考虑 45°；推荐默认 45° 斜俯视，可调整俯角 |

**视觉主张：像在二战作战室里俯看一张正在交战的精致模型沙盘。**

战場材质和 UI 材质分工明确：战场是地形、微缩装备和烟火；纸张、盖章、金属铭牌、机械刻度主要出现在 HUD。不要给整个地形叠强纸纹以致看不清高差。

## 2. 美术语言

### 2.1 形体与比例

坦克保留炮塔、炮管、履带、车体前后等识别结构；装甲种类用体型、炮塔和炮管长度区分，不能只换皮肤。步兵以班阵列呈现，近景可见士兵姿态，中远景仍能辨识班级标记。

地形有大块起伏与明确山脊，不用高频噪声铺满表面。村庄、工事和树林留出战术空隙，重要道路、桥和山口在 45° 视角也要看得清楚。

模型可以适度放大以保证读图：车辆和人体相对建筑略放大，炮管略加粗，弹体和曳光增加可见度。碰撞体、射程与规则尺度保持统一，视觉放大不把坦克凭空变成障碍面积更大的单位。

默认呈现严肃但克制的战争模型感；避免玩具积木式夸张、亮塑料材质、过度圆润的兵器、超长拖尾激光与强漫画爆炸。

### 2.2 材质、照明和地景

装备以哑光涂装为主，少量边角金属反光；适量积尘、磨损，不追求每个铆钉。地形有草地、泥土、道路、岩石的可辨色块；少量精细贴图只在近景生效。

建议首图为温带乡村与小城市：浅黄褐土地、灰绿林地、灰白建筑、清楚山脊。昼间斜光帮助辨认坡度，阴影不可把整片林地压成黑块。动态昼夜与天气不进入首张图的验收。

沙盘感主要来自比例、材质、俯视构图与环境细节，不依赖严重景深。默认不做明显移轴模糊，避免外围战线和文字失焦；可以将轻景深作为近景观战选项。

### 2.3 火力和伤亡

- 步枪：短促闪光、少量曳光、局部尘土；不把每名士兵每发子弹都画成亮线。
- 坦克：炮塔朝向、炮口后坐、明显主炮闪光，弹体与命中产生因果。
- 迫击：弧线高、声响轻于榴弹、短间隔散落。
- 榴弹：跨山可见弧线、较长飞行、落点烟尘与压制。
- 被压制步兵：伏低、停顿、寻找遮蔽；撤退有可读方向，不能像瞬间失去寻路。
- 损毁：坦克残骸保留一段时间，火焰逐渐减弱；步兵死亡克制表现，残骸装饰不能堵死逻辑路径。

默认战场烟尘不得长期遮住全部战况：目标区域的部队轮廓和关键标签保持可见；观战模式可提高烟火质量，仍须保留“降低烟雾遮挡”选项。真实烟幕的 LOS 作用与装饰烟尘分别标记。

## 3. 相机与遮挡

### 3.1 默认相机

默认从地平面量起的俯角 45°，正交投影为初版建议；透视作为实验候选。定义角度参考，避免一个 agent 理解成距竖直 45°、另一个理解成其他参数。

相机俯角允许 35°—70°，旋转 360°；战术总览快捷切到约 70°。滚轮缩放有速度缓冲，所有缩放都限制在可用距离；不强制镜头回到主城。

缩放分三级：

| 层级 | 玩家要看什么 | 显示优先级 |
|---|---|---|
| 总览 | 战线、城市、战区与增援走向 | 班级符号、目标、路线、控制区 |
| 常规指挥 | 兵种、地形、架设与掩体 | 实体模型、状态短标、交战火力 |
| 近景观战 | 士兵、炮塔、炮弹与爆炸 | 模型和演出，必要时隐藏复杂叠层 |

视角与 LOD 切换平滑，但不要平滑关键数字变化或延迟玩家命令确认。

### 3.2 45° 视角下必须处理的遮挡

高山、树冠、建筑挡住选中部队时显示轮廓和投影位置；障碍可在相机遮挡时变淡，但不能因此改变游戏 LOS。透明度属于观察层，射线与路径仍使用实体地形。

框选使用屏幕投影与地面实体，排除装饰和粒子；山后己方单位可通过标识选择。鼠标落点从相机射线与地形求交，不用简单屏幕比例映射，避免高地命令落点偏移。

炮弹预计落点、移动终点都贴在正确地形高度；地表圆可以沿高差投影，不能埋进山坡或浮在空中。重要标签须避让并聚合，不能让二十个班的 HP 条叠在一起。

## 4. HUD 信息架构

### 4.1 基准布局

设计基准 1920×1080，最低验收 1280×720；字体与 UI 比例可调 80%—150%。常规状态中央战场可交互面积目标 ≥70%，不是用六块半透明面板覆盖全屏。

```text
┌─────────────────────────────────────────────────────────────────┐
│ 兵员/军需/收入    人口与后勤    战役意志    时间 / 速度 / 暂停    │
├──────────┬─────────────────────────────────────┬────────────────┤
│ 战区短签 │                                     │ 默认收起       │
│ 北 / 中  │             主要沙盘战场            │ 选中后展开：   │
│ 南       │    战线、单位、目标、火力与道路      │ 单位/设施详情  │
│          │                                     │ 自动/手动状态  │
│ 事件短条 │                                     │ 命令、缺口原因 │
├──────────┴──────────────────────────┬──────────┴────────────────┤
│ 出兵预设 | 单位卡 | 队列缩略 | 托管 │ 小地图 + 图层控制          │
└─────────────────────────────────────┴───────────────────────────┘
```

这是结构示意。首版建议顶栏高 56、底栏高 144，左侧短签宽 120；详情宽 280 按需出现；边距 16，基础间距 8。1280×720 时底栏用可横向翻页的兵种分组，不能把文字缩到看不清。出兵权重编辑打开局部面板，不常驻 12 根滑块。

### 4.2 三层信息

第一层常驻：P/M 余额与每分钟收入、人口、后勤满足度、战役意志、时间倍速、托管状态、战区短签、出兵入口和小地图。

第二层选中后显示：HP、士气、压制、弹药、供给连接、当前命令、架设/维修、目标与阻塞原因。多选显示总数、兵种构成、最低士气、缺供给数量，而不是展示 20 张独立卡。

第三层按需展开：完整出兵配比、城市劳动力、生产资源保护、武器射程和散布、伤害事件、战线压力、补给网络与路线、AI 调试。技术日志和碰撞体开关只在开发工具中，不出现在普通玩家流程。

## 5. 细操与自动执行的衔接

### 5.1 命令优先级

`死亡/淘汰 > 溃退与不可执行状态 > 明确手动撤退 > 当前手动任务 > 战区任务 > 默认自卫`。

自卫与机会射击可以在移动中发生，但不改变手动目的地；命令不是隐形属性加成。安全状态约束仍生效：未架设不能开火、弹药不足不能集火、溃退不能被移动命令硬拉回去。

每单位有 `controlMode`（自动/手动）、`manualTask`、`savedSectorId`、`completionPolicy`。手动覆盖时保留原战区归属，默认不把它从预期兵力统计中完全删除，而标记为暂离。

### 5.2 命令生命周期

| 命令 | 行为 | 何时恢复自动 |
|---|---|---|
| 移动 | 沿可行路径到地表目标，自卫不追击 | 到达容差 8 米后稳定 3 秒；恢复原战区任务，预览已提示 |
| 攻击移动 | 去目标区域，遇敌依照角色交战 | 到达且周围 100 米无可行目标持续 5 秒 |
| 集火 | 攻击指定目标，兵种保留射界与架设限制 | 目标毁灭、敌情过期 15 秒，或 60 秒任务上限 |
| 撤退 | 去安全恢复点，途中自卫能力按武器规则 | 达到重返条件 HP≥70%、Q≥55、A≥.5；或玩家主动恢复自动 |
| 固守此处 | 保持位置与自卫，仍可因溃退逃离 | 明确点击恢复自动，或手动另下命令；不可悄悄超时 |

移动后的自动恢复可能不符合某些玩家预期，因此右键提示“移动，到达后恢复战区”；按 H 固守或点击“移动并固守”可留在目的地。这个差异必须可见，而不是让玩家以为单位不听命令。

目标非法立即反馈，不覆盖原任务。寻路失败返回“目标无法到达”，可在距点击点 20 米内找最近合法位置并显示实际终点；超过范围拒绝。路径途中受堵每 2 秒尝试，10 秒仍失败转安全等待并提示，保留恢复自动按钮，不无限推挤。

“恢复自动”即时取消当前手动任务，在下一次战区更新接回；命令高亮渐隐但不改变单位位置。对同组连续右键替换现有任务；Shift 排队最多 8 条，队列清空后按完成策略恢复自动。

### 5.3 鼠标与键盘建议

| 输入 | 作用 |
|---|---|
| 左键己方单位 / 拖框 | 选中 / 多选；Shift 增减选择 |
| 左键敌方 | 查看可见信息，不取得指挥权限 |
| 右键地面 / 敌人 | 移动 / 集火；下令前用光标区分类型 |
| A 然后左键地面 | 攻击移动 |
| R | 撤退 |
| H | 固守当前位置 |
| G | 恢复自动 |
| Space | 单机暂停/恢复 |
| WASD / 中键拖动 | 相机平移 |
| Q / E | 相机旋转 |
| 滚轮 | 缩放；面板上滚动时不缩放相机 |
| F | 跟随选中单位；移动相机取消跟随 |
| Tab | 打开/关闭战区总览 |
| U | 隐藏 HUD；仍保留可找回的小提示 |
| Esc | 取消下令模式 → 关闭当前面板 → 打开暂停菜单 |

支持键位重映射。输入焦点在文本框时不发战场命令；Alt-Tab 后清除按键保持，避免相机持续飘移。暂停时允许下达命令，恢复后按下一个 tick 执行，AI 同样暂停，没有偷偷继续更新。

## 6. 出兵与托管的交互

单位卡常态显示名称、P/M 成本、在场/上限、下一订单状态和对应战区。不常驻每个单位完整武器面板。

点击卡片打开：权重、最大数量、暂停、战区；“加一支”是单次订单，与持续规则视觉区别明确。配比调整使用可编辑数字和预设；权重不要求用户手工凑 100，后台归一化后显示支出倾向。

生产队列反馈：

| 状态 | 必须显示 |
|---|---|
| 尚未解锁 | 解锁倒计时；保留卡片但禁用立即生产 |
| 缺资源 | 缺 P/M 数字和预计筹集时间 |
| 人口满 | 在场/在产预占/上限；可跳转查看在产 |
| 等待生产位 | 当前任务及预计空闲时间 |
| 已开始 | 进度、已扣成本；取消返还 50% 提示 |
| 完成但出场堵塞 | “等待出口”，不反复扣款、不丢订单 |
| 资源保护 | 明示为哪一支高价订单预留、剩余保护时间 |

托管开关在顶栏/底栏入口常可达；展开经济面板才显示三份额。切换手动保持当前比例，提供“还原均衡”按钮；收入、后勤预测同步变化。不要通过默认弹窗询问每次托管调整。

## 7. 战区、火力与图层

选战区短签时显示目标、姿态、增援比例和兵力摘要；一键切换谨慎/强攻/固守/筑垒/撤收。修改目标进入地面点选，不让拖动 UI 面板同时发出战场命令。

火力任务预览显示：合法射程、最低射程、估计散布、已知友军风险；无法射击显示山体遮挡/角度无解/缺弹/正在架设。散布圈标注“95%”，不能假装是必中圆。

图层最多常用四项：战线、补给、射程/火力、地形/高差。可组合，但强调层应有优先级，不能一次出现五层高饱和覆盖。总览默认战线和任务，补给短缺时只提示局部，不强行打开全图工程图。

## 8. 作战室视觉系统建议

### 8.1 基础色与质感

| Token | 建议值 | 用途 |
|---|---|---|
| paper | #E9DFC8 | 主面板纸底 |
| paperRaised | #F4ECD9 | 选中卡片、说明浮层 |
| ink | #272C27 | 主文字与刻度 |
| inkMuted | #59604F | 次级文字，按实际对比度验收 |
| olive | #4B5945 | 主操作与军用标签 |
| brass | #A77C38 | 强调刻度/待确认状态，不作小字默认色 |
| danger | #A63F36 | 严重损失、撤退、危险提示 |
| border | #B7AA89 | 分隔线与压印边界 |

纸纹低对比、低密度，不进入小字背后；少量角钉和铭牌只在面板边缘。机械仪表适合后勤利用率或意志总览，但数字需同时显示，不能要求玩家读针尖猜“余额 126”。

标题可用窄体/军用标签感拉丁字体配中文黑体；正文优先系统中文可读字体，数字使用等宽/tabular figures。建议正文 14—16 px、关键资源 18—22 px；缩小分辨率通过布局折叠，不能把正文缩成 9 px。

### 8.2 多方颜色

阵营颜色用于徽标、标记和战线，装备只少量涂装/识别条，保留时代气氛。前四方建议蓝 #3D78A8、橙 #BA7D34、紫 #856DA8、青绿 #3F8B83，另备品红和浅青供 6 方扩展。最终对地形的对比度须实机检查。

阵营同时配 I/II/III/IV 标识或独立轮廓图形；危险状态用警示符号，不用另一方阵营色冒充状态。不能以红绿区分友敌成为唯一信息。自由混战保留各方颜色，再由关系图标表达敌对。

### 8.3 动效与反馈

按钮/卡片反馈目标 ≤100 ms，面板展开 150—220 ms；用轻位移和透明度，不大幅缩放 HUD。资源数字刷新不抖布局。战况通知限流：相同原因 5 秒内合并，重大城市警报始终保留。

减少动态效果设置关闭镜头震动、强闪烁和界面滑移，仍保留炮击结果与必要信息。粒子帧率下降时优先减少装饰，不能丢掉弹道、部队标识、命令预览和 UI 反馈。

## 9. 页面与状态清单

**快速开战**：默认配置一屏完成，提供地图、AI 数量/难度/性格、公开/迷雾、速度规则；阵营装备池初版相同。进阶折叠项才显示时间上限、起始资源和随机种子。

**载入**：地图/配置名称和明确进度；文件错误显示原因与返回设置入口，不能停在无限转圈。

**战斗 HUD**：包含正常、暂停、倍速、命令放置、多选、资源缺口、人口满、出场堵塞、目标失效、供给中断、溃退和淘汰观战状态。

**结算**：胜负原因、持续时间、出兵/损失、控制变化、资源支出、供给中断和关键事件；提供再来一局、保存回放、回主界面。伤害数字不是唯一评分，以阵地和战局贡献辅助解释。

**设置**：UI 缩放、键位、音量分组、色觉辅助、烟雾强度、镜头震动、俯角/旋转和性能档位。单机核心功能不依赖在线服务登录。

## 10. 美术交付与 UX 验收

每个地面单位至少需要正常、移动、攻击、受压制/受损、撤退和死亡演出；架设单位额外展开/收起；工兵额外施工/维修。美术命名与单位 ID 对齐。阶段不要求为所有单位单独制作每种动作，可用共享骨架/简单变换，但不能缺失关键状态表达。

至少验收：

1. 1920×1080、1280×720、超宽屏和 UI 150% 下没有关键控件相互遮挡。
2. 45° 时山后己方单位仍可识别/选择，地面命令与火力预览落点正确。
3. 框选 20 个单位能下令；已溃退者明确说明无法强攻，其他可执行单位正常执行。
4. 默认不操作经济、只调出兵，也能完成 30—45 分钟局；托管原因可查看。
5. 默认公开沙盘能观赏全部阵营；切迷雾后图层、日志、散布提示和状态栏不泄露未知敌情。
6. 常驻主文字对比度目标 ≥4.5:1；图层和阵营身份有颜色以外编码。
7. 纯键盘可暂停、打开主要面板、选战区和发主要命令；鼠标悬停不是查看必要信息的唯一方法。
8. 隐藏 HUD 后可用 U 或可见小提示恢复，不能无法找回；Esc 不误取消已执行撤退。
9. 加速时交互反馈仍即时，输入不随着模拟负载积压数秒。
