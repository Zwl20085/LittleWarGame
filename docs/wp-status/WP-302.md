# WP-302 — 3.0.2 armoured-assault round — status

Minor version on `main` after 3.0.1 (a8e80a5). User instruction: tank ammo consumption −90 %,
tank resupply rate +100 %, tank hp +30 % — maximise armoured-assault strength. No full test run
(user instruction); typecheck + the logistics / supply / rules / armour test files only.
